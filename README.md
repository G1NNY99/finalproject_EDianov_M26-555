# CurrencyTrade Hub

Консольное приложение на Python для отслеживания валютных кошельков и симуляции покупки и продажи валют.

Проект разрабатывается в рамках итогового задания Яндекс Практикума.

## Возможности

- Регистрация пользователей с хранением хеша пароля и индивидуальной соли.
- Авторизация пользователя в текущей консольной сессии.
- Просмотр валютного портфеля и его общей стоимости.
- Симуляция покупки валюты за USD.
- Симуляция продажи валюты с зачислением выручки в USD.
- Получение прямых и обратных валютных курсов.
- Кеширование курсов с ограничением срока актуальности.

На текущем этапе операции используют демонстрационные фиксированные курсы. Подключение внешних источников данных предусмотрено последующими этапами проекта.

## Технологии

- Python 3.12 и выше.
- uv — управление проектом, зависимостями и сборкой.
- Ruff — форматирование и статический анализ Python-кода.
- Git — контроль версий.
- JSON — локальное хранение пользователей, портфелей и курсов.
- argparse — обработка пользовательских команд.

Зависимости проекта определены в `pyproject.toml` и зафиксированы в `uv.lock`.

## Установка

Необходимо установить Python 3.12 или выше, Git и uv.

Клонирование репозитория:

```cmd
git clone https://github.com/G1NNY99/finalproject_EDianov_M26-555.git
cd finalproject_EDianov_M26-555
```

Установка зависимостей и подготовка виртуального окружения:

```cmd
uv sync
```

uv создаст виртуальное окружение `.venv` и установит зависимости проекта.

## Запуск приложения

Находясь в корневом каталоге проекта, выполните:

```cmd
uv run python main.py
```

После запуска программа отображает приглашение:

```text
ValutaTrade Hub. Для списка команд введите help, для выхода — exit.
>
```

Все пользовательские команды вводятся внутри запущенного приложения после символа `>`.

Для завершения работы:

```text
exit
```

## Команды CLI

| Команда | Назначение |
|---|---|
| `register` | Зарегистрировать пользователя |
| `login` | Войти в систему |
| `show-portfolio` | Показать портфель и общую стоимость |
| `buy` | Купить валюту за USD |
| `sell` | Продать валюту за USD |
| `get-rate` | Получить валютный курс |
| `help` | Показать справку |
| `exit` | Завершить приложение |

### Регистрация

```text
register --username alice --password demo1234
```

После успешной регистрации создаются пользователь и пустой валютный портфель.

### Авторизация

```text
login --username alice --password demo1234
```

Авторизованный пользователь сохраняется в памяти до завершения текущего запуска программы.

### Просмотр портфеля

```text
show-portfolio
show-portfolio --base EUR
```

По умолчанию общая стоимость рассчитывается в USD.

### Покупка валюты

```text
buy --currency BTC --amount 0.01
buy --currency EUR --amount 10
```

Стоимость покупки списывается с USD-кошелька. Купленная валюта зачисляется в соответствующий кошелёк, который при необходимости создаётся автоматически.

### Продажа валюты

```text
sell --currency BTC --amount 0.01
sell --currency EUR --amount 5
```

Продаваемая сумма списывается с валютного кошелька, а выручка зачисляется в USD-кошелёк.

### Получение курса

```text
get-rate --from EUR --to USD
get-rate --from USD --to BTC
```

Программа выводит прямой и обратный курс, а также время обновления данных.

## Особенности торговой симуляции

Операции `buy` и `sell` являются учебной симуляцией. Реальные денежные средства и криптовалюты не используются.

На текущем этапе регистрация создаёт пустой портфель с нулевыми активами. Покупка требует достаточного USD-баланса; при его отсутствии операция отклоняется.

Отдельная команда начального пополнения USD пока не реализована. Во время функционального тестирования начальные балансы задаются во временных тестовых JSON-данных.

Примеры покупки и продажи выше показывают синтаксис команд, а не гарантируют успешное выполнение на только что созданном пустом портфеле.

## Хранение данных

Приложение использует три JSON-файла:

- `data/users.json` — пользователи, идентификаторы, хеши паролей, соли и даты регистрации.
- `data/portfolios.json` — портфели и балансы валютных кошельков, связанные с пользователями через `user_id`.
- `data/rates.json` — кеш валютных курсов и метаданные обновлений.

Файлы создаются с начальными значениями `[]`, `[]` и `{}` соответственно.

Пароли пользователей в открытом виде в JSON не сохраняются.

## Курсы валют и кеширование

Функция `get_rate()` сначала проверяет локальный кеш `data/rates.json`.

Срок актуальности кешированной записи — **5 минут**.

Если свежий курс найден, используется сохранённое значение. Поддерживается также обратная валютная пара.

Если подходящей свежей записи нет, текущая версия использует демонстрационные фиксированные курсы из `EXCHANGE_RATES` в `core/models.py`.

После получения курса кеш обновляется. Запись содержит курс и время обновления, а метаданные позволяют определить источник данных.

Демонстрационная заглушка обозначается как `Stub`.

**Важно:** на этом этапе курсы не являются актуальными рыночными котировками. Операции `buy`, `sell` и расчёт портфеля также используют фиксированные значения из `EXCHANGE_RATES`.

## Подключение Parser Service

Интеграция с внешними API предусмотрена следующим этапом разработки и пока не реализована.

По техническому заданию планируется использовать:

- CoinGecko — для криптовалют.
- ExchangeRate-API — для фиатных валют.

После реализации Parser Service источники курсов будут подключаться через соответствующие API-клиенты, а полученные значения — сохраняться в локальном хранилище.

Для ExchangeRate-API предусмотрена переменная окружения:

```text
EXCHANGERATE_API_KEY
```

В Windows CMD переменную можно задать для текущего сеанса:

```cmd
set EXCHANGERATE_API_KEY=ВАШ_API_КЛЮЧ
```

Ключ должен храниться вне исходного кода и не должен публиковаться в GitHub. Реальный API-ключ нельзя добавлять в `README.md`, `pyproject.toml` или отслеживаемые Git файлы.

На текущем этапе ключ не требуется: используется демонстрационная заглушка. После реализации Parser Service этот раздел будет дополнен фактическими инструкциями запуска и настройки.
